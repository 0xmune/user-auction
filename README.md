# User Auction (유저 경매)

숲(SOOP) 스트리밍 롤 멸망전에서 팀장이 실시간으로 팀원을 경매하는 웹앱입니다.

## 실행 방법

> ⚠️ Google Drive 동기화 폴더에서는 `npm install`이 파일 잠금 오류(EBUSY/EPERM)로 실패할 수 있습니다.
> C드라이브 등 로컬 폴더에 복사한 뒤 설치/실행하는 것을 권장합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속. 같은 네트워크의 다른 사람은 `http://<내 IP>:3000`으로 접속 가능합니다.

## 사용법

1. **방장**: "방 만들기"에서 방장 이름, 경매 순서(입력순/랜덤), 팀 수(2~8개)와 각 팀 이름·팀장 닉네임·포인트를 입력 후 방 생성.
2. 방 생성 후 경매 목록(선수 이름, 한 줄에 한 명)을 추가.
3. "경매 시작"을 누르면 첫 선수부터 실시간 경매 시작.
4. **팀장**: 방 코드 + 등록된 팀장 닉네임으로 입장 → 입찰가 입력 후 입찰.
5. 입찰 시마다 타이머(12초)가 리셋되며, 시간이 끝나면 자동으로 최고 입찰팀에게 낙찰(입찰이 없으면 유찰).
6. 방장은 "즉시 낙찰"로 강제 낙찰하거나 "다음 선수"로 넘어갈 수 있습니다.
7. 모든 선수 경매가 끝나면 팀별 최종 구성이 표시됩니다.

## 특징

- 실시간 동시 경매 (Socket.io)
- 팀 2~8개, 팀별 포인트 개별 설정
- 경매 목록 입력 순서 또는 랜덤 순서 선택
- 방 코드 + 닉네임 인증 (팀장 닉네임 일치 시 자동으로 팀장 권한 부여, 그 외는 관전자)
- 데이터는 인메모리 저장 (서버 재시작 시 초기화)
